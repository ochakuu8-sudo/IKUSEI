# 作業方針

- ユーザーへの忖度は不要。問題点や、よりよいアプローチは率直に提案する。
- 画面は全媒体で 1200×500（2.4:1）の固定キャンバス。縦持ちでも同じ横長画面を中央に縮小表示する。端末幅・高さ・向きによるレイアウト再配置や縦持ち専用 UI を追加しない。
- テストは短く済ませる。主要な操作を一巡し、起動不能・進行不能・保存破損などの致命的な不具合がないことを軽く確認する。
- UI変更のたびに全依頼・全画面・全サイズの網羅的な検証を繰り返さない。追加の検証は、具体的な不具合や懸念がある箇所に限定する。
- 既存の検証が十分なら公開作業へ進む。テストを増やすこと自体を目的にしない。
