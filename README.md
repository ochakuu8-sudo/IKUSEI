# IKUSEI

育成シミュレーションのブラウザ試作。人物・素材・支援の割当は仮データです。

## 起動・検証

```sh
npm ci
npm run dev
npm run build
npm test
npm run sim
```

Node.js 22.12以降を使用してください。シミュレーションは28日と84日の複数方針を比較します。最適収入や面白さを保証するものではありません。

ブラウザ検証は別ターミナルでViteを起動した状態で行います。

```sh
npx playwright install chromium
npm run test:ui
```

標準接続先は http://127.0.0.1:5173/IKUSEI/ 。変更する場合は `IKUSEI_TEST_URL` を設定します。画像とレポートはリポジトリ外の `../command-validation/` に出力されます。通常はChromiumで主要経路を確認し、別ブラウザは `IKUSEI_BROWSERS` で指定できます。

## 遊びを試す

1. 自室の「薬の依頼を見る」から通常依頼を確認。採集・仕入れで素材を集め、調合した薬を納めて資金を得ます。
2. 通常依頼は繰返し利用できます。複数の依頼書を選び「まとめ納品」で合計を確認すると、1日で全件納品できます。
3. 通算2〜5日に特別依頼Aを引き受け、8日目に薬湯2個を納品すると、学院に新しい人物が登場します。
4. 通算9〜12日に特別依頼Bを引き受け、第2章1日（通算15日）に薬湯2個を納品すると、薬草園・短いイベント・処方・追加依頼が開きます。
5. 「出かける」から人物を選ぶと、薬以外の頼まれごとや掛け仕入れを相談できます。画面を開く操作は0日です。

特別依頼は在庫がなくても前金で引き受けられますが、納品は指定日当日だけです。前日は準備済みでも納品できません。当日は通常依頼とまとめて納品できます。約束帳で日程・残額・返還義務を確認してください。

保存はv9。v7/v8の資源や関係を維持し、旧予約契約は当時の期限・納品方法・延長条件を引き継ぎます。旧契約の1日納品はまとめ納品にも参加できます。

仕様はGAME_DESIGN.md §15、構成はSYSTEM_PLAN.md §10、検証結果はVALIDATION.md。特別依頼はsrc/content/support.ts、イベントはsrc/content/events.ts、人物・場所・通常依頼はsrc/game.tsで差し替えられます。

GitHubのmainへのpushと、Pagesへのデプロイは別操作です。公開手順はCLAUDE.mdを参照してください。

## 行動一覧から遊ぶ

自室には「薬の依頼を見る／調合する／出かける／休む」の4つの行動が固定した順番で並びます。選ぶと、その行動の対象一覧・詳細が開きます。「戻る」は直前の選択へ、「自室へ」は行動一覧へ戻ります。画面を見るだけでは日数を使いません。

通常依頼の「この薬を準備する」から対象の薬と入手先へ進めます。商会への近道では必要素材の購入候補をまとめて表示し、購入を自分で確定します。調合後は納品へ戻れます。準備メモは義務を発生させません。

「出かける→商会」では「素材を買う／人物に会う」を選びます。人物を選んでから頼まれごとや親交を確認できます。調合は数量指定・0日、素材と体力の消費は個別操作と同じです。在庫は自室の「持ち物」から確認できます。

約束帳は期限順の一覧と14日予定表です。日付を押すと予定表を開きます。仕入れの数量や納品選択、表示設定は進行セーブと別に保存されます。初期化と中盤の試作メニューは設定内にあります。
