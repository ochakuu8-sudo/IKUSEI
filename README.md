# IKUSEI — 没落令嬢の返済録

没落した令嬢が、毎日届く依頼を選びながら借金返済を進めるブラウザゲームです。

現在は、既存の試作を土台に**完成版へ向けた企画・仕様を再整理する段階**です。

条件付きADVと育てられる4項目（交渉・知見・胆力・魅力）を実装しています。タイトルの「はじめから」で開始し、保存後は「続きから」で再開します。現在の本編は、検証用に作った7つの仮依頼を共用しています。育成 → 選択の解放 → 後続依頼を確認できます。本文・選択待ち・結果を途中保存し、通った経路を回想できます。人物・台本・数値は仮置きです。差し替え方は [ADVコンテンツ制作ガイド](docs/ADV_CONTENT_AUTHORING.md) を参照してください。

記録は同じブラウザー・同じ配信元の保存領域に残ります。複数タブから進めた場合、古い記録を持つタブは保存を止め、「最新の記録を読み込む」へ案内します。更新前のコードを開いたままのタブにはこの保護がないため、ゲーム更新時は各タブを再読み込みしてください。保存形式はv16のままで、v13〜v15の移行も維持しています。

尊厳三軸はランク5〜0の6段階です。下がったランクは戻らず、数値は同じランク内だけ回復します。独立した品位上限は廃止しました。境界・条件の書き方・旧保存の移行は [尊厳ランクの仕様](docs/ADV_CHOICE_CONDITIONS.md#17-尊厳の不可逆ランク制2026-09-10確定) を参照してください。

UIは現在、商業品質の基準に未達です。[UI品質管理基準](docs/UI_QUALITY_STANDARD.md)と[改善の実装指示](docs/UI_QUALITY_IMPLEMENTATION.md)に、文字・操作の実寸、画面別条件、検証・公開判定を定めています。基準の文書化とUIの修正は別であり、追加の品質テストも今後実装します。

## リポジトリの見方

- `src/` — 現在動いているゲーム本体。現状を確認するときの一次情報です。
- `public/` — ゲームで使用する画像などの公開素材。
- [docs/](docs/README.md) — 完成版に向けた企画・仕様・実装指示。各文書の状態欄で実装状況を確認してください。
- `old/` — これまでの企画書、実装計画、UI案、制作メモ等のアーカイブ。**現行仕様ではありません。**

過去資料には、すでに廃止・変更された設計が多数含まれています。新しい設計を検討するときは `old/` を前提にせず、必要な履歴を確認するときだけ参照してください。

## 開発

```sh
npm ci
npm run dev
```

```sh
npm run build
npm test
```

ブラウザー試験は、別のターミナルで `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort` を起動してから実行します。必要なら初回に `npx playwright install chromium` で試験用ブラウザーを用意してください。

```sh
npm run test:ui
npm run test:adv-ui
npm run test:save-ui
npm run sim
```

- `test:ui` は、旧保存に残る依頼を含む31件の表示・受諾条件・章末精算などを確認します。表示用フィクスチャでは優先度を外しています。本編の提示優先度と後続依頼の解放はADVのテストで確認します。
- `test:save-ui` は2タブの日送り・精算・同時開始・再読込を確認します。Web Locksと、未対応環境向けIndexedDBの排他処理をChromium上でそれぞれ実行します。
- `sim` は本編のADV受諾・条件判定・選択効果・終了・章末精算を通して、3方針を各24周比較します。方針は効果を知ったうえでの貪欲選択であり、初心者の行動や最適攻略を再現するものではありません。回数は `IKUSEI_SIM_RUNS`、ブラウザー試験URLは `IKUSEI_TEST_URL` で指定できます。
