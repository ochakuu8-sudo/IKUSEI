# IKUSEI — 没落令嬢の返済録

借金を負った令嬢が、届いた依頼から「稼ぐ・学ぶ・休む」を選ぶブラウザゲームです。

現在の本編は **第1章「最初の返済」の無料体験版**。14日間、依頼6件、主人公と主要な依頼人2人に絞りました。導入、7日目の約束、後続依頼、最初の返済と結末まで遊べます。買い物は追加していません。

交渉・知見・胆力・魅力の4成長と、貞操・品位・威厳の3尊厳を維持。学んだ経験で継続的な仕事の手当を得られます。尊厳の下がったランクは戻りません。期限に返済できなかった分と利息も記録されます。

第1章の終了後は、余剰金・成長・尊厳・約束を残して第2章の開始位置で待機します。**第2章の内容はまだ収録していません。** 制作範囲・保存仕様・続編の追加方法は [第1章体験版の実装](docs/CHAPTER_ONE_DEMO.md) にまとめています。本文の最終推敲、専用CG・BGM、初見によるプレイ時間・難度の確認は今後の制作です。

「設定 → データ」でセーブをファイルに書き出し、別ブラウザーや配信元へ持ち運べます。複数タブで進めた場合は古いタブからの上書きを止めます。旧v13〜v16保存、受諾済みの旧台本、以前の回想は保持します。第2章以降の旧進行を第1章へ巻き戻しません。

## 開発・確認

```sh
npm ci
npm run dev
npm run build
npm test
```

ブラウザー確認は `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort` を起動してから実行します。初回に `npx playwright install chromium` が必要な場合があります。

```sh
npm run test:chapter-ui
npm run test:save-ui
npm run test:adv-ui
npm run test:ui
npm run sim
```

- `test:chapter-ui`：体験版の導入・選択途中の再開・章末・回想・ファイル移行を確認。
- `test:save-ui`：Web LocksとIndexedDB代替処理で、2タブの競合・再開・精算・保存失敗後の再試行を確認。
- `test:adv-ui` / `test:ui`：開発専用フィクスチャで、旧保存の依頼31件と条件付きADVの回帰を確認。通常プレイの依頼範囲とは別です。
- `sim`：公開済みの章を4方針で比較。既知効果に基づく固定方針で、初見や最適攻略の再現ではありません。

本体は1200×500の固定キャンバス。縦画面や小画面も縮小表示で操作できます。画面サイズを理由に操作を遮断しません。品質の確認範囲と残件は [第1章の確認記録](docs/CHAPTER_ONE_REVIEW.md) を参照してください。

## リポジトリ

- `src/campaign.ts`：公開する章、依頼、人物、物語の発生時期。
- `src/content/chapterOne.ts`：第1章の依頼と本文。追加手当・成長・約束の分岐。
- `src/content/scenarios.ts`：台本登録と、精算済みの記録から結末を組む処理。
- `src/` とテスト：現在の動作の一次情報。
- `public/`：公開素材。`preview/` は比較見本で、本編進行とは別。
- [docs/](docs/README.md)：現行仕様と確認結果。
- `old/`：過去資料。現行仕様として扱いません。

GitHub Pages： https://ochakuu8-sudo.github.io/IKUSEI/

Viteの出力は相対パスです。itch.ioなどへ配る場合は、`dist/index.html` がZIPの直下になるように固めます。詳細は [第1章体験版の実装](docs/CHAPTER_ONE_DEMO.md#配信と未完了の制作) を参照してください。
