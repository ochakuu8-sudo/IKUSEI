# IKUSEI

育成シミュレーションのブラウザ試作。人物・素材・支援の割当は仮データです。

## 起動・検証

```sh
npm ci
npm run dev
npm run build
npm test
npm run sim
```

Node.js 22.12以降を使用してください。シミュレーションは28日と84日の複数方針を比較します。最適収入や面白さを保証するものではありません。

ブラウザ検証は別ターミナルでViteを起動した状態で行います。

```sh
npx playwright install chromium
npm run test:ui
```

標準接続先は http://127.0.0.1:5173/IKUSEI/ 。変更する場合は `IKUSEI_TEST_URL` を設定します。画像とレポートはリポジトリ外の `../workday-validation/` に出力されます。Chromiumで主要経路と6サイズを確認します。シーンは `npm run test:scenario`、タッチ経路は `npm run test:touch`（接続先は `IKUSEI_TOUCH_URL`）で確認できます。

## 遊びを試す

1. 自室の「仕事をする」から通常依頼を確認。採集・仕入れで素材を集め、調合した薬を納めて資金を得ます。
2. 通常依頼は繰返し利用できます。複数の依頼書を選び「まとめ納品」で合計を確認すると、1日で全件納品できます。
3. 通算2〜5日に特別依頼Aを引き受け、8日目に薬湯2個を納品すると、学院に新しい人物が登場します。
4. 通算9〜12日に特別依頼Bを引き受け、第2章1日（通算15日）に薬湯2個を納品すると、薬草園・短いイベント・処方・追加依頼が開きます。
5. 「出かける」から人物を選ぶと、薬以外の頼まれごとや掛け仕入れを相談できます。画面を開く操作は0日です。

特別依頼は在庫がなくても前金で引き受けられますが、納品は指定日当日だけです。前日は準備済みでも納品できません。当日は通常依頼とまとめて納品できます。約束帳で日程・残額・返還義務を確認してください。

保存はv9。v7/v8の資源や関係を維持し、旧予約契約は当時の期限・納品方法・延長条件を引き継ぎます。旧契約の1日納品はまとめ納品にも参加できます。

仕様はGAME_DESIGN.md §15、構成はSYSTEM_PLAN.md §10、検証結果はVALIDATION.md。特別依頼はsrc/content/support.ts、イベントはsrc/content/events.ts、人物・場所・通常依頼はsrc/game.tsで差し替えられます。

GitHubのmainへのpushと、Pagesへのデプロイは別操作です。公開手順はCLAUDE.mdを参照してください。

## 行動一覧から遊ぶ

自室の主行動は「仕事をする／出かける／休む」。調合・持ち物・設定は小さい補助操作です。画面を開く操作は0日で、確定ボタンに実際に使う日数を表示します。

「仕事をする」には通常の薬納品、人物の依頼、特別依頼を同じ一覧に表示します。種別・人物・状態で絞り込め、既に見た仕事は紹介条件を失っても理由付きで残ります。納品可能な依頼はモード切替なしで複数選択できます。

薬の詳細には不足する薬・素材と入手先を表示。「不足分を買う」「採る」は直接確認画面へ進み、実行後は同じ依頼に戻ります。その場で数量を指定して調合し、納品まで進められます。通常の調合画面は処方帳として残ります。

外出先は人物・採集地・商会を直接選択します。人物の依頼を見る操作は仕事一覧の人物フィルターです。採集は直接確認画面、商会は直接数量入力を開きます。地図と一覧を切り替えるタブはありません。

日数を使う通常行動は結果確認後に自室へ戻り、準備行動だけ元の詳細に戻ります。章末・結末は優先して表示します。期限警告は確定ボタンの直前に置き、スマホの戻る操作も下部に揃えます。

約束帳・14日予定表はHUDの日付から開きます。自室には期限当日や返還待ちの通知を表示します。進行セーブはv9のまま、納品選択・準備メモ・見た仕事・設定は独立したUI保存領域です。

シーンは全画面の画像とコンパクトな文字だけを表示。画面タップで全文表示・次送り、長押し・上スワイプ・「⋯」でログやセリフ非表示を開きます。最後まで読むまで未読イベントを保持します。
