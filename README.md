# IKUSEI

薬の依頼を確認し、素材を集め、調合して納める育成ゲームのブラウザ試作。人物・素材・報酬は仮データです。

## 遊び方

1. 「依頼」で薬と必要数を確認する。
2. 足りない素材を「収集」で採る、または買う。
3. 「調合」で薬を作り、元の依頼へ戻って納品する。
4. スタミナが残っていれば、その日のまま行動を続ける。
5. 「一日を終える」で翌日へ進み、スタミナを100まで回復する。

通常依頼は事前受注不要で繰り返し納品可能。特別依頼は前金で受諾し、指定日当日に納品します。日付から約束と返済予定を確認できます。薬以外の常設仕事・親交訪問・休憩はありません。

新規開始から丘で採集→薬湯2個調合→学院へ納品すると、1日目のまま450G・スタミナ34になります。処方は薬の取引による関係成長や特別依頼で増えます。

セーブv10はv7〜v9を引き継ぎます。旧契約も新方式に統一し、納品や延長で日付を進めません。旧セーブの資産・期限・未読イベントは維持します。

## 開発・確認

Node.js 22.12以降。

```sh
npm ci
npm run dev
npm run build
npm test
npm run sim
```

起動中のViteに対して npm run test:ui / npm run test:scenario / npm run test:touch を実行します。UIの接続先はIKUSEI_TEST_URL、タッチはIKUSEI_TOUCH_URLで指定できます。初回は npx playwright install chromium が必要です。検証画像は ../stamina-validation/ に出力します。

28日・84日のシミュレーションは通常販売・まとめ納品・特別依頼優先・関係優先を比較します。従来の返済ノルマを据え置いているため、スタミナ制では資金に大きく余裕が出ます。本編バランスは未確定です。
