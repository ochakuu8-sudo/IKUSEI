# IKUSEI — 没落令嬢の返済録

薬を仕入れ・制作・納品し、品質と依頼に伴う出来事から次の取引先を開くブラウザゲームです。第一章8依頼は差し替え可能な検証用コンテンツ。本文・数値は本番確定ではありません。

## 起動

Node.js 22.12以降。

```sh
npm ci
npm run dev
```

Viteに表示された `/IKUSEI/` のURLを開きます。全端末で1200×500の縦横比を固定し、横持ちでのプレイを想定しています。

## 遊び方

1. 依頼の必要品・期限・紹介条件を確認します。反復依頼は事前受諾不要。一度限りの契約は2件まで受諾できます。
2. 準備を始め、仕入れマップから採集または購入します。
3. レシピと制作数を選び、完成予定の品質を確認して調合します。
4. 依頼へ戻り、高品質優先・低品質優先・手動のいずれかで在庫を選び、報酬を確認して納品します。
5. 一日を終えると期限が判定され、翌朝スタミナ100へ回復します。14日目は章末精算です。

旧セーブはv13へ自動移行し、元データのバックアップを残します。品質のない旧在庫は品質40へ変換。受諾済み旧契約と掛け仕入れは約束帳から扱えます。

## 開発・確認

```sh
npm run build
npm test
npm run test:ui
```

UI確認はVite起動中に行います。既定は `http://127.0.0.1:5174/IKUSEI/`。別ポートなら `IKUSEI_TEST_URL` を指定してください。初回は `npx playwright install chromium` が必要です。

`npm run test:touch` / `npm run test:scenario` は今回の短いUI経路を使用します。`npm run sim:chapter` は第一章の固定操作経路と参照値を照合します。`npm run sim` は残してある旧v12エンジンの比較用で、v13のバランス評価ではありません。

## データの差し替え

- `src/content/chapter1.json`：価格、品質曲線、採集地・店、8依頼、本文、イベント効果。
- `docs/IMPLEMENTATION_SPEC_v1.md`：元の実装仕様と追加指示。
- `docs/IMPLEMENTATION_STATUS.md`：変更範囲、互換性、確認済み・未実施項目。

受諾済み契約の数量・金額・期限・イベント定義は保存した条件を使います。意味の異なる出来事には新しいIDを割り当ててください。
