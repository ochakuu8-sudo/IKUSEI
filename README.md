# IKUSEI — 没落令嬢の返済録

没落した令嬢が、毎日届く依頼を選んで借金を返すブラウザゲームの試作です。1日1行動、全6章×14日。本文・数値は本番確定ではありません。

[ブラウザで遊ぶ](https://ochakuu8-sudo.github.io/IKUSEI/)

## 起動

Node.js 22.12以降。

```sh
npm ci
npm run dev
```

Viteに表示された `/IKUSEI/` のURLを開きます。全端末で1200×500の縦横比を固定し、横持ちでのプレイを想定しています。

## 遊び方

1. 横に並ぶ3枚の依頼状で、相手・報酬・消費体力・三値の代償を比べます。
2. カードを開き、詳しい条件と紹介されなくなる依頼を確認して受諾します。場面と結果を経て翌日へ進みます。
3. 体力は翌日へ持ち越します。「今日は受けない」を選ぶと1日を使って全回復します。
4. 14日目に章の返済を精算します。関係や失った依頼、回想は台帳から確認できます。

左に立ち絵・体力・所持金・三値、上に日付・残債・返済期限を表示します。三値は紋、関係は輪、体力は砂時計とゲージで示します。体力不足でも依頼状は読めますが、受諾はできません。

採集・調合・在庫管理の生産ラインはv14で廃止しました。保存はv14で、v13からは返済・尊厳・評判を引き継ぎ、元の保存と回想は残します。

## 開発・確認

```sh
npm run build
npm test
npm run test:ui
npm run sim
```

UI確認はVite起動中に行います。既定は `http://127.0.0.1:5174/IKUSEI/`。別ポートなら `IKUSEI_TEST_URL` を指定してください。初回は `npx playwright install chromium` が必要です。

`npm test` は1日1行動エンジンと回想、`npm run sim` は現行ルールの章ごとの収入を確認します。UIテストは依頼選択から翌日までの操作に加え、横3枚の配置と体力不足時の詳細閲覧・受諾禁止を検査します。

## 実装と公開

- `src/game.ts`：依頼24件・人物・代償・台本・返済額。
- `src/daily.ts`：抽選・1日1行動・章末精算。
- `src/DailyApp.tsx` / `src/chapter.css`：依頼状カード・状態パネル・詳細・台帳。
- `CLAUDE.md` 冒頭：現行ルールとUI。`GAME_DESIGN.md` には旧版の履歴も含みます。
- `docs/IMPLEMENTATION_STATUS.md`：変更範囲、互換性、確認済み・未実施項目。

`main` はソース、`gh-pages` はビルド生成物です。`main` へのpushだけでは公開されません。公開手順は `CLAUDE.md` のデプロイ節を参照してください。
