# IKUSEI

育成シミュレーションのブラウザ試作。人物・素材・支援の割当は仮データです。

## 起動・検証

```sh
npm ci
npm run dev
npm run build
npm test
npm run sim
```

Node.js 22.12以降を使用してください。シミュレーションは28日と84日の複数方針を比較します。最適収入や面白さを保証するものではありません。

ブラウザ検証は別ターミナルでViteを起動した状態で行います。

```sh
npx playwright install chromium
npm run test:ui
```

標準接続先は http://127.0.0.1:5173/IKUSEI/ 。変更する場合は `IKUSEI_TEST_URL` を設定します。画像はリポジトリ外の `../ui-check/` に出力されます。

## 支援と約束を試す

1. 第1章を始め、自室の「支援を相談する」または仕事一覧から「支援と約束」を開く。
2. 条件を読み、予約前金または掛け仕入れを受ける。
3. 素材を調合して約束帳から納品、または代金を支払う。
4. 履行すると追加の支援が開く。予約注文の納品方法には資源と日数の異なる選択肢がある。
5. 再交渉で期限を延長できる。解消・不履行でも未精算は残り、支払うまで同じ相手の新規支援は停止する。

支援は各章1回、同時2件。受諾済みの条件はセーブに保存されます。v7の既存セーブは新たな義務を後付けせず移行します。

`src/content/support.ts` で支援元・素材・期限・選択肢を差し替えられます。`validateOffers` とテストで参照の整合性を確認してください。現行ルールと仮数値は `GAME_DESIGN.md` §14。

GitHubのmainへのpushと、Pagesへのデプロイは別操作です。公開手順は `CLAUDE.md` を参照してください。
