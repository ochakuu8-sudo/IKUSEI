## 読み方と更新方針

各文書では、合意済みの方針、初期実装の仕様、検証用の仮例、未決事項を区別します。例示された技能・人物・数値を、そのまま本番仕様として採用しないでください。

既存の依頼・主人公以外の人物・台本は、システム構築用の仮置きです。今後の本番コンテンツは別途設計します。

実装が進んだら、該当文書の状態欄と更新記録を更新してください。実装済み・未実装を混ぜて記述しないでください。

UIの変更と台本の差し替えには、UI品質管理基準も適用します。機能テストの通過はUI品質の合格を意味しません。新しい基準を満たしているかは、作業ごとの確認記録で判定します。

旧資料は `../old/` に保存しています。**現行仕様としては参照しません。** 過去資料を新仕様へ自動的に引き継がず、必要な事項は改めて合意して記述します。
