# 書簡UIの本編反映（2026-09-10）

- 対象：採用済みの改善プレビューに沿い、本編の依頼一覧・便箋・休息確認の紙面・日付と返済・尊厳3軸と成長4項目を変更。Cの革装、Dの墨刷りの封筒、小さい名前札、取り付け部のある綴じ金具を使用。実際のデータから名前・本文・報酬・関係・失ったランク・次の成長境界を描画する。
- 外観：Chromium、1280×720と844×390で一覧・便箋を目視。論理キャンバス1200×500は維持。V01は人物と手紙の構図、V02〜V04は素材・二重罫・繊細な文字組み・控えめな操作表示、V05は封筒から便箋への意匠の継続、V06は失った段階と成長境界の刻みを確認した。ノベルへの遷移では一枚絵の画面が表示され、依頼画面の意匠が混入しないことを確認。
- 機能：ビルド成功。依頼の開封→受諾→本編ノベルの到達、受諾直後に報酬や経験が増えないことを確認。初回の確認コードに保存項目名の誤りがあったため、その短い経路のみ修正後に再確認。全ボタン・全シナリオの巡回は行っていない。条件判定・報酬計算・保存形式は変更していない。

## 範囲と残件

対象の通常表示・受諾経路で進行を妨げる不具合は見つからなかった。長い本文や多数の代償は既存のスクロール領域で全文に到達する構造を維持。全種類の長文データ、全ブラウザー、実機、台帳・回想・結果画面全体の新たな美術評価は未実施。作品全体の商業品質合格とは扱わない。

既存の成長・尊厳の詳細説明画面は維持する。プレビュー内だけの例示数値、表示例スイッチ、仮の署名処理は本編に含めない。

## 少しポップな動きの追加（2026-09-10）

- 封筒は短い時間差で届き、触れると小さく持ち上がる。開封360ms・戻し210msに軽い弾みを加え、署名と薔薇の印が260msで反応する。数値や依頼名は動かさず、常時ループは入れていない。配置と素材は維持。
- 受諾は既存の保存処理を先に確定してから署名を見せる。保存できなければ署名を表示せず、再開時は受諾済みの物語から続く。連打は同一の受諾を増やさない。OSとゲーム内の「動きを減らす」設定では新しい動きを省略する。
- ビルド成功。1280×720でホバー→開封→戻る→開封→署名→本編到達を1経路確認し、署名中の保存済み状態、連打でも単一セッション、受諾直後の報酬・経験が未付与であることを確認。844×390のOS動作縮減では登場・開封・署名の省略を確認。実時間の録画と代表フレームを取得し、ホバーと署名中の画像を目視した。全ゲームの操作巡回はしていない。
