# 1日1行動への差し戻し（v14）

2026-09-06。`src/DailyApp.tsx`・`src/daily.ts`・`src/game.ts` が現行。
`IMPLEMENTATION_SPEC_v1.md` と v13 の生産ラインは**この版で廃止した**。

## なぜ戻したか

v13は「採集→仕入れ→調合→納品」を1日に収めるためスタミナ制（1日2〜4行動）に
変えていた。選択の重さは1日にできる回数に反比例するので、毎日の決定が
「重い1回」から「軽い3回」へ薄まり、企画書の中心（毎日どれを差し出すか）が消えていた。
実測では1納品16タップに対して決定は2回、場面は全編で8回（納品243回中）だった。

## 何が変わったか

- 1日 = 1行動。毎日3件＋「今日は受けない」。選ぶと日が終わる。
- 体力は日をまたいで持ち越し、休んだ日にだけ満タンに戻る。
- 依頼は `src/game.ts` の24件・6種別（調剤／親交／社交／実務／人前／労務／裏）。
  `needs` で上の依頼が閉じ、`opensBelow` で裏が開く。代償は依頼ごとに固定。
- 受ける前に、代償の紋と払ったあとの値、**その行動で閉じる依頼**を出す。
  閉じた依頼は台帳に跡として残る。
- 依頼を受けたら必ず場面が入る（`sceneScript`）。品の格・払った軸・関係の段階で変わる。
- 採集・仕入れ・調合・在庫・品質・熟練・契約・掛け仕入れは削除。
- 保存は v14。v13からは返済・尊厳・評判だけを引き継ぎ、v13の保存は消さない。
