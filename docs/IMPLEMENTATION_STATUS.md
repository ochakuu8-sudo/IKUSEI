## 実装内容

- 仕入れマップ：紹介済みの入手先を割合座標で選択。採集と購入の詳細・利用不可理由・不足素材・カゴ・店舗別単価を表示。
- 保存乱数による各主要素材2～4個の独立抽選と追加素材。プレビューは範囲・確率だけを返し、失敗や取消では抽選しません。
- レシピ別XP／Lv／完成品質。1個ずつ品質を決めてからXPを加算するため、一括制作途中のレベルアップに対応。
- 品質別完成品在庫。総数の別保存はしません。
- 高品質優先／低品質優先／手動割当による多品目・複数依頼の納品。報酬の丸め、買い叩き、当日最高評価との差分による関係上昇、別契約の在庫不足警告。
- 第一章8依頼。反復4件、一度限り4件、同時受諾2枠、指定日と期間納品、辞退・取消・受付終了・不履行、受諾時の条件とイベント定義のスナップショット。
- 初回処方、仲介窓口・管理者の紹介、薬草園、backmarketの解禁。受諾後は新規紹介条件が変化しても納品できます。
- C1-07の一度限りの支給と、納品時の貞操・品位・品位上限変化。発生済み／閲覧済み／未読キューを分離。イベントのスキップ・ログ・非表示・再読み込みを維持。
- 準備目標・複数品目・品質選択・フィルター・スクロール位置をUI保存。調合から別の必要処方へ切り替え、元の依頼へ戻れます。
- v13保存。v7～v12を既存処理で正規化してから移行。旧在庫を品質40へ、旧関係を0/2500/6000/10000へ変換。旧債務・契約・処方・未読イベントを保持。
- 旧保存のrawバックアップ、不整合通知、保存失敗時の同じ結果の再保存、状態の版番号による古い確認の拒否と連打ガード。
- 章末返済・繰越・全6章の経済ループ。第二章以降の反復依頼は維持し、専用物語が未設定であることを画面に明記。

本文・画像は依頼と接続した仮コンテンツです。新規CGは生成していません。
