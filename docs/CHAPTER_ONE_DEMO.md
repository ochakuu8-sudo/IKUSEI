# 第1章体験版の実装

2026-09-11。状態：第1章の範囲・本文・進行・保存・終了を実装。買い物は採用せず、借金返済を維持。専用CG・BGMの完成、初見プレイ時間の測定、itch.ioの作品ページ公開は今回の完了範囲に含めない。

## 遊べる範囲

- 第1章「最初の返済」、14日間・1日1行動。初期所持金120G、最初の返済1,050G。
- 主要人物は主人公エレオノール、商会のヴェルネ、学院のクレール。自室・商会・学院の既存背景を使用する。
- 交渉・知見・胆力・魅力の4成長、貞操・品位・威厳の3尊厳、体力、関係、通い詰めによる基本報酬の値引きを残す。
- 仕事は6件。通常プレイに検証用7件・旧依頼24件・未制作の人物や旧エンド収集欄を提示しない。旧IDと台本は受諾済みセーブ・以前の回想を壊さないために残す。

| 依頼 | 基本報酬 / 体力 | 役割と受付 |
|---|---|---|
| 商会の帳簿仕事 | 95G / 20 | 毎日。手当65G、または交渉・胆力のいずれか経験1 |
| 学院の書庫整理 | 80G / 16 | 毎日。手当40G、または知見・魅力のいずれか経験1 |
| 取引の最終確認 | 120G / 25 | 3日目以降の奇数日。交渉か胆力1段階で追加100G。補助には条件なし |
| 食い違う資料の調査 | 105G / 22 | 4日目以降の偶数日。知見か魅力1段階で追加105G。補助には条件なし |
| 自分の名前で結ぶ契約 | 255G / 28 | 商会を選んだ場合の10〜14日目、一度だけ。任意の広告契約は追加100G・威厳の数値25低下。断っても完了 |
| 資料に添える一枚 | 230G / 22 | 学院を選んだ場合の10〜14日目、一度だけ。知見か魅力の経験1 |

表は基本値。基本報酬には関係と通い詰めが反映され、手当は選択時の固定加算。成長1段階には経験2が必要。先に2日学び、残りの仕事で手当を得る配分を選べる。

基礎2件は常時確保し、第3枠を成長を使う2仕事で交互に使う。約束の後続依頼が届いている間は後続を優先する。先延ばしで後続が消える抽選は行わない。後続を終えれば成長の仕事へ戻る。1〜2日目は基礎2件のみ。

同じ依頼の2回目以降は短い再訪文から役割選択へ進む。毎回長い導入を読み直させない。4成長を独立した長編4ルートには分けない。

## 屋敷の維持費

毎日の行動（依頼・休息のどちらも）の終わりに、屋敷の維持費 60G を引く。章末精算そのものは1日ではないので引かない。その日の所持金で払いきれない分は借金へ積み、所持金は0で止まる。尊厳には触れない。

金額は `src/game.ts` の `DAILY_UPKEEP`。仮値であり、依頼の報酬・返済額と併せて再調整する。

導入の意図は、選択肢の比較を「どれが一番多く貰えるか」から「今日の1日が何を生むか」へ移すこと。維持費が無いと、どの依頼を選んでも所持金は単調に増えるだけで、配分の判断が生まれない。

固定方針シミュレーション（1日60G、第1章の必要額1,050G）の精算前所持金は次のとおり。

| 維持費 | 収入優先 | 序盤から育成 | 中盤から育成 | 尊厳維持・関係優先 |
|---|---|---|---|---|
| 0G（導入前） | 1,872 | 2,356 | 1,835 | 2,256 |
| 40G | 1,312 | 1,796 | 1,275 | 1,696 |
| 50G | 1,172 | 1,656 | 1,135 | 1,556 |
| **60G（現行）** | **1,032（不足）** | 1,516 | **995（不足）** | 1,416 |
| 70G | 892（不足） | 1,376 | 855（不足） | 1,276 |

60Gが、育成しない方針と育成が遅い方針が返済に届かなくなる境目である。効果を知ったうえで選ぶ固定方針の比較であり、初見難度の測定ではない。

休息のみで14日を過ごすと、120Gの初期資金では2日分しか払えず、残り12日分720Gが借金へ積まれる。返済は0Gになる。

## 章のつながり

1. 導入「最初の手紙」。返済期限、行動と休息、不足時の持越しを伝える。
2. 7日目の行動後「七日目の約束」。商会か学院、後半の約束を一つ選ぶ。休息だけでも選べる。
3. 14日目の行動後に精算。満額・不足のいずれでも結末へ進む。
4. 「次の手紙」。約束の相手、実際に後続を完了したか、広告を受けたか、返済結果で本文を変える。
5. 体験版の記録画面。返済・手元・残債、回想、保存ファイルの書き出し、タイトルへ戻る操作を表示する。

自動の物語は追加の日数・体力・報酬を発生させない。本文位置、選択、完了フラグ、回想を通常ADVと同じ保存で扱う。結末の返済明細は保存済みの精算結果から作り、読む・再開する・回想する操作では再精算しない。

## 第2章への接続

`src/campaign.ts` の `campaignChapters` は**公開した章だけ**を登録する。現在は1のみ。実装内に残る旧全6章の数値は互換のための既存値であり、全6章を今回の制作範囲として確定したものではない。

第1章の精算後は `chapter=2`、`day=1`、`ended=false`。所持金、残債、不足と利息、成長、尊厳、関係、約束、資格、回想、章別の精算結果を保持する。次章に章内一回依頼を受けられるよう、章内履歴だけは従来どおり更新する。未公開の章では、新しい依頼・休息・再精算を拒否する。

続編実装時は以下を行う。

1. 新しい依頼・台本を登録し、`campaignChapters[2]` に第2章の依頼ID・人物・イベントを追加する。
2. 第1章のフラグ（`ch1.promise.vernet`、`ch1.promise.claire`、`ch1.followup.*`、`ch1.advertised`等）を条件として参照する。過去の選択を尊厳値から推測しない。
3. 第1章の精算済み保存をそのまま読み込む。新規開始や経験値の初期化を行わない。第1章の結末を読み終えていない場合は先にその続きを表示する。
4. 第2章の返済額・依頼・体力と利息の負担を改めて調整する。登録件数だけを増やして第1章の仕事を繰り返させない。

接続試験ではテスト内だけに第2章の依頼を登録し、書き出した第1章保存から第2章2日目まで進め、残債・成長・尊厳・精算履歴の保持を確認する。これは第2章の制作済みを意味しない。

## 保存ファイルと旧記録

本編キーは `ikusei-prototype-save-v16` を維持する。追加した `chapterResults` がない旧v16は空配列として読み、日付や金額を変更しない。v13〜v15の従来の移行も残す。既に第2章以降へ進んだ保存は巻き戻さず、未公開範囲の保管画面を表示する。受諾済みの依頼は保存した台本で完了できる。

「設定 → データ」で書き出し・読み込み。「体験版の記録」からも書き出せる。ファイルは `format=ikusei-save`、`version=1` のJSONで、本編とADV回想を含む。16MBまで。読み込み前に形式・状態・途中の台本を検証し、プレイヤーが対象記録を確認してから進行を置き換える。回想は併合し、旧進行の直前コピーを `ikusei-prototype-save-v16-import-backup` に残す。

本編とADV回想は配信元をまたいでファイル移行できる。表示設定・既読スキップ用メタデータ・旧一本道ギャラリーはブラウザー側に残す。旧回想は削除せず、「以前の記録／以前の場面回想」から参照する。
